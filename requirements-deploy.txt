# WHY THIS FILE EXISTS, separately from requirements.txt:
#
# On Linux, `pip install torch` installs the CUDA build by default - roughly
# 2-3 GB of GPU libraries. This project has no GPU and never will: torch is
# here only because sentence-transformers uses it to run MiniLM embeddings on
# CPU during deduplication. The CPU-only wheel is about 200 MB instead.
#
# That difference decides whether the app fits inside a free tier at all.
# The line below points pip at PyTorch's CPU-only index for torch alone;
# everything else comes from PyPI as usual.
--extra-index-url https://download.pytorch.org/whl/cpu
